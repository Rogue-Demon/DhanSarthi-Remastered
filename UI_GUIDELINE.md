धनSarthi--- UI & Design Guidelines

Purpose

This document defines the official design system for धनSarthi

Every page, component, layout, animation, color, typography, spacing,
and interaction must follow this document.

The AI must not use any design style outside these guidelines.

------------------------------------------------------------------------

🚨 Highest Priority Rule

This document is the single source of truth for the user interface.

If any design suggestion conflicts with another document, always follow
this UI guideline.

Do not redesign, reinterpret, or substitute styles.

------------------------------------------------------------------------

🎯 Design Vision

The application should feel like a premium AI-powered fintech platform.

Keywords:

-   Premium
-   Modern
-   Clean
-   Friendly
-   Intelligent
-   Minimal
-   Interactive
-   Soft
-   Elegant

Users should immediately feel that the application is trustworthy,
professional, and easy to use.

------------------------------------------------------------------------

🎨 Design Style

Official Style

Claymorphism (Primary)

Every major UI component should follow Claymorphism principles.

Examples

-   Cards
-   Sidebar
-   Navbar
-   Buttons
-   Statistics
-   Inputs
-   Chat Containers
-   Modals
-   Charts Containers

Characteristics

-   Soft shadows
-   Rounded corners
-   Soft highlights
-   Floating cards
-   Smooth depth
-   Soft gradients

Avoid

-   Flat Design
-   Heavy Skeuomorphism
-   Harsh Shadows
-   Brutalist Design
-   Complex Decorations
-   Glassmorphism as the primary style

Only show the navigation items relevant to the selected profile.

-   Fixed
-   Clean
-   Minimal

🏆 Final Design Goal

The finished interface should look like a modern AI-powered fintech
product that could compete visually with leading financial platforms.
Every screen should feel polished, premium, cohesive, and trustworthy
while following the Claymorphism design language with a purple-centric
gradient theme. Student dashboards should feel engaging and motivating,
while Working Professional and Business dashboards should emphasize
minimalism, clarity, and data-driven decision-making.This gives
Anti-Gravity a strict UI rulebook so it won't randomly switch between
Material Design, Glassmorphism, Neumorphism, or other styles. It also
clearly defines the different visual personalities for Students
(interactive) versus Working Professionals and Businesses (minimal,
executive) while keeping the overall product visually consistent.
